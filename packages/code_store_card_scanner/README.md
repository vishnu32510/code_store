# code_store_card_scanner

Modular debit and credit card scanning, real-time regex brand detection, and interactive card details package for Flutter applications.

## Features
- **Offline Card Scanning**: High-speed offline card OCR scanner powered by `card_scanner`.
- **Real-Time Regex Brand Detection**: Identifies Visa, Mastercard, American Express, Discover, JCB, Diners Club, UnionPay, Maestro, and Elo.
- **Dynamic Postfix/Suffix Icon**: Visual card brand badge displayed directly inside the Card Number input field.
- **Interactive 3D Card Preview**: Realistic credit card preview that updates dynamically and flips when CVV is focused.
- **Robust Validation**: Luhn algorithm checksum verification and expiry date validation.
- **Mock/Simulator Fallback**: Testing presets and simulated scans when camera hardware is unavailable.
