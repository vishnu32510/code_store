# `code_store_theme`

Pure Dart & Flutter dynamic theme engine with ThemeBloc, system/dark/light mode synchronization, persistence, and custom theme data configurations.

---

## 📱 Required Permissions & Native Setup

* **No native permissions required.** `code_store_theme` is a pure Flutter/Dart package.

---

## 🚀 Quick Start
```dart
// Wrap your MaterialApp with ThemeWrapper
ThemeWrapper(
  child: MyApp(),
);
```
