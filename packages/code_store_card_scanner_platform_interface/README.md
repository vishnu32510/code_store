# code_store_card_scanner_platform_interface

The common platform interface for [`code_store_card_scanner`](../code_store_card_scanner).

This package defines the common `CardScannerPlatform` interface and `CardCameraFrame` data structure implemented by platform-specific packages such as:
- `code_store_card_scanner_ios` (Apple Vision)
- `code_store_card_scanner_android` (Google Play Services ML Kit)
